# 🎬 CineGame Central - Enciclopedia Visual

Proyecto web interactivo desarrollado para la materia de Desarrollo Web.

## 🚀 Sitio Web en Vivo
👉 https://yandelozua.github.io/enciclopedia-peliculas/

---

## 📌 Descripción del Proyecto
CineGame Central es una enciclopedia visual interactiva que permite a los usuarios explorar películas y videojuegos, consultar información relevante y guardar sus elementos preferidos en una sección de favoritos.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica del contenido.
- **CSS3:** Diseños dinámicos y estilos en modo oscuro.
- **JavaScript (ES6):** Dinamismo y lógica de la sección de favoritos.
- **Git & GitHub Pages:** Control de versiones y publicación en internet.

---

## 📋 Resumen de Sprints
- **Sprint 1 (HTML):** Maquetado base y secciones del catálogo.
- **Sprint 2 (CSS):** Estilos visuales y diseño adaptativo.
- **Sprint 3 (JS):** Lógica interactiva para favoritos.
- **Sprint 4 (Lanzamiento):** Publicación en GitHub Pages y README.md.
